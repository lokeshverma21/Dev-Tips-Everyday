# Coding Tip #43: Write Clean and Readable Code

Writing clean and readable code isn’t just for the benefit of others—it helps *you* too. Clear code is easier to debug, maintain, and scale. When you're working on a large project, readability becomes essential for long-term success.

**Tip**: Stick to consistent naming conventions, add comments when necessary, and break complex logic into smaller functions.

Example:
```js
// Bad: Confusing variable names and lack of comments
let a = 20;
let b = 5;
let c = a / b;

// Good: Meaningful variable names with comments
let totalItems = 20;
let itemsPerPage = 5;
let totalPages = totalItems / itemsPerPage; // Calculate number of pages
```

By making your code easy to understand, you’ll reduce confusion and save time when you or others need to revisit it later.
